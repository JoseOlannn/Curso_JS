# Curso de JavaScript - DevF

Este repositorio contiene las actividades y ejercicios del curso de JavaScript impartido en DevF.

## Estructura del Proyecto

| Carpeta | Descripción |
|---------|-------------|
| `actividad1/` | Tipos de datos en JavaScript |
| `actividad2/` | Evaluador de notas con mensajes personalizados |
| `actividad3/` | Clasificación de frutas (arreglos, objetos y ciclos) |
| `actividad4/` | Seguimiento de libros (funciones) |
| `actividad5/` | Crear objeto a partir de un Libro (POO) |
| `actividad6/` | Caja de comentarios (DOM y eventos) |
| `actividad7/` | Generador de contraseñas (HTML/CSS/JS) |
| `actividad8/` | Seguimiento de libros con comentarios (DOM y eventos) |

## Tecnologías

- JavaScript (ES6+)
- HTML5
- CSS3
