# Curso de JavaScript - DevF

Este repositorio contiene las actividades y ejercicios del curso de JavaScript impartido en DevF.

## Estructura del Proyecto

### Módulo 1: Fundamentos
| Carpeta | Descripción |
|---------|-------------|
| `Modulo 1/actividad1/` | Tipos de datos en JavaScript |
| `Modulo 1/actividad2/` | Evaluador de notas con mensajes personalizados |
| `Modulo 1/actividad3/` | Clasificación de frutas (arreglos, objetos y ciclos) |
| `Modulo 1/actividad4/` | Seguimiento de libros (funciones) |
| `Modulo 1/actividad5/` | Crear objeto a partir de un Libro (POO) |
| `Modulo 1/actividad6/` | Caja de comentarios (DOM y eventos) |
| `Modulo 1/actividad7/` | Generador de contraseñas (HTML/CSS/JS) |
| `Modulo 1/actividad8/` | Seguimiento de libros con comentarios (DOM y eventos) |

### Módulo 2: Algoritmos y Node.js
| Carpeta/Archivo | Descripción |
|-----------------|-------------|
| `Modulo 2/actividad1/` | Planificador de viajes (ECMAScript 6 y módulos) |
| `Modulo 2/actividad2.js` | Lista de compras (Arrays y Arrow Functions) |
| `Modulo 2/actividad3.js` | Filtro y orden de productos (Map, Filter, Sort) |
| `Modulo 2/actividad4.js` | Encuentra los invitados (Dos punteros) |
| `Modulo 2/actividad5.js` | Palabra más larga (Sliding Window) |
| `Modulo 2/actividad6.js` | Buscar un regalo (Recursión) |
| `Modulo 2/actividad7.js` | Buscar el máximo (Divide and Conquer) |
| `Modulo 2/actividad8/` | Gestor de notas (Módulo `fs` de Node.js) |

### Módulo de React: Ejercicios de `useState` y `useEffect`
| Carpeta/Proyecto | Descripción |
|------------------|-------------|
| `ejercicios-react/` | Aplicación con múltiples componentes que demuestran el uso de los hooks `useState` y `useEffect` en React. |

#### Cómo ejecutar el proyecto de React
1. Abre tu terminal.
2. Navega a la carpeta del proyecto:
   ```bash
   cd ejercicios-react
   ```
3. Instala las dependencias (si no lo has hecho):
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre en tu navegador la dirección `http://localhost:5173`.
