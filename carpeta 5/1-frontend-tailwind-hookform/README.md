# Proyecto de FrontEnd Avanzado con React - Parte 1

## Propósito de la Primera Entrega
En la rama `parte-1` debes integrar **Tailwind CSS** para el estilo y **React Hook Form** para la validación de formularios. Esta configuración inicial te permitirá sentar las bases para las siguientes etapas del proyecto.

## Objetivo
Configurar tu entorno local, crear un repositorio propio en GitHub y trabajar en una rama específica para esta entrega (`parte-1`).

## Instrucciones de la Entrega
1. Crea un repositorio nuevo en tu cuenta de GitHub.
2. Usa el repositorio base solo como referencia para entender la estructura y lógica (`https://github.com/carlosDevf/DevfSeek`).
3. En tu nuevo repo, crea la rama `parte-1` y realiza ahí todos tus cambios:
   ```bash
   git checkout -b parte-1
   ```
4. Integra Tailwind CSS para los estilos y React Hook Form con Zod para los formularios.
5. Haz commits claros y mantén la historia de tu rama limpia:
   ```bash
   git add .
   git commit -m "feat: integracion de Tailwind CSS y React Hook Form con validacion Zod"
   ```
6. Evita trabajar directamente en `main` o `master` para esta entrega.

---

## Cómo ejecutar esta entrega

1. Navega a esta carpeta:
   ```bash
   cd "carpeta 5\1-frontend-tailwind-hookform"
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre en tu navegador la URL que aparece en consola (usualmente `http://localhost:3001` o `http://localhost:5173`).
